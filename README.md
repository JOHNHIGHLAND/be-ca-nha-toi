# ASCIIquarium Deluxe — Bể Cá Ký Tự ASCII Trực Tuyến (22 Loài)

Dự án web bể cá nghệ thuật ký tự ASCII lấy cảm hứng từ lệnh `asciiquarium` trên Linux Terminal, được nâng cấp đồ họa ánh sáng dưới nước, 22 loài sinh vật biển & tàu thuyền động cùng tương tác trực tiếp.

## Cách chạy
Giải nén file ZIP và mở trực tiếp file **`index.html`** bằng trình duyệt bất kỳ (Chrome, Edge, Firefox, Safari).

## Phím tắt nhanh
- **Click chuột trái** vào mặt nước: Thả mồi cho cá ăn (hoặc click trúng **Cá Nóc** để làm cá phồng gai!).
- **Phím `Space`**: Rải thức ăn khắp bể.
- **Phím `B`**: Phun luồng bong bóng lớn từ đáy bể.
- **Phím `H`**: Ẩn/hiện toàn bộ thanh điều khiển (chế độ màn hình chờ / screensaver).
- **Phím `F`**: Bật/tắt chế độ toàn màn hình.
